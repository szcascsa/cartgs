大型逐row数据、NPZ/BIN冻结输入与排序集合、完整tree、runtime库、可执行文件和日志继续保留在原本地/服务器实验目录，未删除。它们不是本次Git提交的一部分；具体included/omitted路径、大小与SHA256见 `git_archive_manifest.json`。
