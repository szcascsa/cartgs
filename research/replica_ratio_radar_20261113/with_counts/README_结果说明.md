# Replica质量与保留Gaussian数

实线沿用原版质量雷达图与原始等距刻度；同色虚线表示该方法每个Ratio的平均保留数K。质量看左刻度，点数看右刻度；三种指标及三种模式共用K范围0–70000，右刻度以千点显示。

平均K和质量使用同样的8场景／16组等权方式，均读取已有原始汇总，不重新训练或渲染。K为全局保留模型的Gaussian数／Renderer输入数，不能理解为当前视角实际可见点数。

CaRtGS随机删除与Opacity删除保留K完全相同，虚线重合；蓝金使用交错线段显示，未人为移动曲线。图下表列出每种方法逐Ratio的平均K，单位千点，显示两位小数，完整精度见CSV。

实线质量越外越好；虚线越外仅表示点数更多。相同Ratio时各方法的N和K不同，本图不是相同K试验。
