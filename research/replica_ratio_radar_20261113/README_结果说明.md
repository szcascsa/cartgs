# Replica按Ratio的雷达图

三张主图分别为PSNR、SSIM与LPIPS。蓝色为CaRtGS随机删除，金色为CaRtGS Opacity排序删除，红色为我们全局LoD。

综合图使用office0–4、room0–2共8个场景：先平均同场景单目与RGB-D的全轨迹成绩，再对8场景等权平均。这等价于16组场景／模式等权平均，不按帧数加权。分模式附图分别对8场景等权平均。

PSNR统一使用0–40 dB径向刻度；SSIM使用0–1；LPIPS反向显示，中心1、外圈0，标注值仍为原LPIPS。所有图越靠外越好，没有逐Ratio归一化、平滑或变更原数值。圆周各Ratio是离散类别，等角度不表示实际数值距离。

我们使用已有全局导出的结果，不混入局部Ratio结果。两个删除基线均无补偿或再训练，随机仅seed0一次。删除预算K=floor(r×N_CaRtGS)，各方法实际K不同，不能称同K试验。
