# Replica全局／局部Ratio对比

每场景先平均单目与RGB-D，再对8个场景等权平均，不按轨迹帧数跨场景加权。场景：office0、office1、office2、office3、office4、room0、room1、room2。

蓝色为CaRtGS随机删除，金色为CaRtGS Opacity删除，红色为我们全局Ratio，绿色为我们局部视角Ratio。实线为质量，同色虚线为平均保留K。红色数字仅标注全局版指标，局部完整指标见CSV。质量保持原版等距刻度：PSNR 0–40，SSIM 0–1，LPIPS反向1–0。

局部的每个场景／模式／Ratio先对所有已评价视角的实际保留K求算术平均，读取评价汇总actual_K_mean，再按与质量一致的相机模式和场景等权平均。不是ratio乘全局N，也不是逐视角Alpha合成可见点数。全局K为导出模型保留数。图下表单位为千点，显示两位小数，CSV保留完整精度。

CaRtGS两种删除方法K相同，虚线路径重合，用蓝金交错线段显示。各方法和全局／局部的候选池及实际K不同，属于同Ratio比较，不是同K或固定相机位姿对照。各自评价帧数及源路径保存在逐场景CSV。随机删除只有seed0。本次不重新训练或渲染，保留之前三方法图。
