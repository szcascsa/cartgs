# Replica跨视角去重保留总数

每场景先平均单目与RGB-D，再对8个场景等权平均。

局部点数定义为U=|∪ᵥ Sᵥ|，Sᵥ为当前视角实际选中并提交的母Gaussian原始ID集合。一个点只要在任何评价视角被选中过就计入一次，不随出现帧数或补偿位置重复计数。逐帧选点哈希与原评价完全一致，原均值K_mean仍保存在CSV，图中虚线和表格读取unique_total。

CaRtGS两删除版本及我们全局版使用固定保留集大小；不同场景／相机模式先分别去重，再等权汇总，不会将不同模型的ID混在一起去重。实线质量和原始等距刻度不变。蓝色随机删除，金色Opacity删除，红色我们全局Ratio，绿色我们局部Ratio。

该点数表示整个评价轨迹累计需要的唯一母Gaussian数量，不是每帧渲染工作量。只统计既有评价视角，轨迹覆盖以逐场景CSV帧数和源路径为准；不改旧指标，不重新训练或渲染图片。
