# Compensator 蒸馏的跨场景验证协议

本轮选择 TUM fr1_desk RGB-D、Replica office0 RGB-D、Replica office3 RGB-D 和 VECtor corner-slow 单目，覆盖四个新场景与三类数据。每个场景读取其已经训练好的冻结 Teacher、Master、Selector 和 Anchor Feature，独立训练 3534 参数的 32/32 Compensator 学生。测试对象是既定蒸馏流程的可复用性，各场景使用对应的模型和 Feature 坐标系。

每场景统一执行四阶段。初始蒸馏 6000 步、lr=0.001、图像每20步权重1；图像校准2000步、lr=0.001、每5步图像权重1000；几何校准6000步、lr=0.0002、每步图像权重200、原始残差权重0.01；连续Ratio校准3600步、lr=0.0001、50%轮转档位加50%相邻区间log均匀采样，其余同几何校准。各阶段从上阶段best初始化，重置Adam和采样RNG。所有场景seed=0，参数与步数固定，不按新场景结果调参。

固定六档为[.01,.05,.1,.3,.5,.7]，另外评价[.03,.08,.2,.4,.6]五个非锚点Ratio。全局和局部模式分别记录逐视角指标。连续采样覆盖Ratio区间，非锚点具体测试值与离散训练档位区分。

使用完整保存的估计相机轨迹，RGB时间戳最近关联阈值为0.001秒，要求全部轨迹帧一一匹配。TUM与VECtor从rgb.txt读取图像时间戳，Replica从results/frame*.jpg读取帧编号。使用原RGB及checkpoint中的相机分辨率，不重采样图片。每5帧的视角池被蒸馏训练排除，其中三个均匀分布视角用于选模，剩余池中固定32帧用于评价。教师和地图已见过同一条轨迹，因此这是学生留出视角评价。

前三阶段的六个验证Ratio沿用既定规则，最后阶段加入五个相邻档位几何中点。监督目标和检查点选择只使用Teacher属性和Teacher图像，GT仅用于评价。对比图像校准、几何校准和连续Ratio校准三个阶段的各自best。

质量门限沿用每Ratio每模式平均PSNR损失≤0.01dB、p99≤0.05dB、最坏≤0.1dB。报告均值和尾部，并记录PSNR、SSIM、LPIPS、Teacher/Student图像MSE、实际K、XYZ/Scale偏差、训练步数与模型哈希。教师与学生共享选点身份，全局沿用原有阈值和同分语义，局部沿用名义Anchor候选池和严格K。

每次只运行一个本轮GPU进程。共享GPU下记录训练墙钟和峰值显存，速度比较等待GPU空闲。生产目录、共享环境、原模型及Gaussian Rasterizer二进制均以前后SHA核验。只保存模型、数值结果和报告曲线，渲染图片保存数为0。
