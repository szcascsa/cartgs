# 冻结部署三项优化验收方案

对照为已验收 v27 的独立部署入口。实验使用 TUM fr1_xyz 与 Replica office3 真实 checkpoint，模型、相机、固定 Gumbel、实际候选集与请求保持配对。

## 候选与验收

- Selector 固定物理输入首层前缀采用逐 Gaussian、逐神经元的原顺序十项 FMA。缓存不含 Bias。运行时从该 FP32 值继续累加第 11 项及后续动态输入。
- 视角编码仅处理本帧候选构建所产生的可见 Anchor。每次请求重新计算可见性与可见 Anchor 编码。
- 小 K Compensator 首轮比较原 CTA、四项局部展开与八项局部展开。变慢候选归档后继续比较 16 点四累加器、8 点双累加器与 4 点单累加器 Tile，保留独立的大 K 路径。

全部候选先通过前向、分数、ID、属性和像素逐位比较，再测性能。覆盖空集、极小 K、ratio 轮转、旧 11D 和新 19D、非默认 Stream、输出存储所有权、Graph 开关和配置切换。

## 性能口径

CUDA Event 单独测组件，Nsight Systems 统计准备阶段节点、计算和同步。跳转相机与变化预算的端到端测试分别报告 prepare 与 prepare 加原 Rasterizer。A/B 轮换执行，记录 GPU 时钟、温度与其他 PID。共享 GPU 期间的墙钟结果单独注明，避免推断独占设备收益。

## 空间边界

固定前缀每点 32 个 FP32，严格 128N 字节。对象更换 checkpoint 或拓扑时重建。构造私有冻结快照，禁止对同一部署实例训练或修改私有参数。关闭前缀时释放该 Tensor 并清空 Graph 计划。

可见编码沿用原有有界工作区，局部循环展开沿用原有激活空间。最终报告初始化耗时与新增显存。

## 质量标准

优先要求 v27 与候选的所有输出和像素逐位一致。如果出现 FP32 差异，先定位具体算子，再独立验证平均 PSNR 降幅不超过 0.01 dB、99% 视角不超过 0.05 dB、最差不超过 0.1 dB。未经验证的差异候选不能成为最终默认。
