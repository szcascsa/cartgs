# 三数据集全部场景/相机模式 mode182 加速比报告

32组：Replica 8场景×Mono/RGB-D，TUM 5场景×Mono/RGB-D，VECtor 3场景×Mono/Stereo。共59,507个有效全轨迹视角，Full加11档ratio，各1轮；本版计时714,084行。

入口：JointReleaseRenderer(mode=182, reuse=True, fused=True, finish=True)，每组使用自己的冻结3534参数Student及匹配Master。这轮只测速度，不把蒸馏质量或GT质量门限当作通过；历史部署检查状态保留在SCENES_FROZEN.json。

每个视角仅渲染一张图；VECtor Stereo表示双目训练checkpoint的单张左图输出，不是左右两图总耗时。分辨率分别为Replica 1200×680、TUM 640×480、VECtor 1224×1024，首尾原始RGB尺寸已核验。

Full是该场景/模式全部未补偿Master高斯。局部ratio按名义Anchor候选池M计算严格K=min(floor(r×M),eligible)。加速比为各视角Full中位数耗时除以ratio中位数耗时，再对视角取算术平均，未混用跨场景Full。

纯渲染只计JointReleaseRenderer同一native实例的native.render CUDA Event；准备和网络在计时外。完整调用使用当前CPU位姿的render_from_source同步Host墙钟，包含准备、选点、补偿、渲染与finite检查。

每组先独立smoke和12视角×12条件的RGB/radii/选点ID逐位核验，再全轨迹计时；第一版仅正序一轮，最终版含正序、倒序、seed0随机顺序；方法和范围顺序轮转。预热有界容量计划，正式计时无计划未命中。每500帧以内整块按前后2秒外部负载验收。

## 完整性与限制

输入/代码保护文件前后哈希比较720项全部通过；接受150个负载干净的计时块，弃用1块。未训练、未改生产项目或共享环境、未保存渲染图片、未commit/push。

TUM fr1_room Mono移除356条完全相同的时间戳/位姿重复行，仅评价978个独立视角；未更改原轨迹文件。各组覆盖与重复记录见reports/COVERAGE.csv。

曲线展示平均值，不保证每个视角都更快；慢于Full的视角数量和5%/95%分位见SUMMARY.csv。不同场景地图大小、图像分辨率、Gaussian footprint和遮挡均不同，跨场景曲线差异不能全部归因于网络。两种耗时范围独立记录，不能用纯渲染倍数代替端到端收益。
