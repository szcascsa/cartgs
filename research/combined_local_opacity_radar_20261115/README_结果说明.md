# 三数据集合并的局部方法与CaRtGS Top-K对比

Replica 8场景×2模式=16组，TUM 5场景×2模式=10组，VECtor 3场景×2模式=6组，共32组。每组先使用既有全轨迹平均指标，再对32组直接算术平均。每组权重1/32；数据集贡献分别为50%、31.25%、18.75%。没有按帧数加权，也没有将三个数据集均值各赋1/3权重。PSNR按已有dB值平均。

只展示两个方法：金色CaRtGS Opacity Top-K保留，绿色我们局部视角Ratio。Top-K保留最高不透明度的K个点，K=floor(ratio×CaRtGS自身地图N)。质量沿用未校正原图的既有评价。同Ratio下各方法实际点数不同，各自估计轨迹也不同，因此不是固定相机位姿、同K对照。

PSNR、SSIM、LPIPS各一张独立扇形雷达图，高斯点数单独一张。质量保持原等距刻度：PSNR 0–40，SSIM 0–1，LPIPS反向1–0；越外质量越好。点数图使用线性刻度，越外仅表示点数更多。

局部总数U=|∪ᵥ Sᵥ|：每个场景／相机模式／Ratio分别对所有评价视角选中的Master Gaussian ID去重，重复出现或补偿坐标改变仍只算一个。Top-K使用固定保留集合的大小。随后将32组总数平均。U不是单帧平均渲染量，也不是Alpha实际贡献点数。原逐视角平均K和地图N保留在CSV中。

输出4张单图和1张总览；PNG为450 DPI，另有SVG和PDF。逐值检查原始指标、352项并集统计来源、32组完整覆盖、Decimal独立均值及8条SVG曲线坐标。全部旧文件只读复用，没有训练或重新渲染。
